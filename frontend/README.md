# TICA COMPUTERS - Frontend

This is the frontend of the TICA COMPUTERS website built using the MERN stack. The main purpose of this website is to showcase our services online. Users can sign up, log in, browse computer courses, access course details, view instructors, and download materials like notes, PDFs, and PPTs.

## Features

- **Home Page**: Overview of the institute.
- **Courses Page**: List of available courses.
- **Course Details Page**: Detailed information about each course.
- **Instructor Page**: Information about course instructors.
- **Materials Page**: Access to notes, PDFs, PPTs, etc.
- **Material Details Page**: Specific information about each material.
- **Students Page**: Dedicated section for students.
- **About Page**: Information about the institute.
- **Contact Page**: Get in touch with the institute.

## Tech Stack

- **React.js**: Frontend library.
- **Redux**: State management.
- **React Router**: Client-side routing.
- **CSS/SCSS**: Styling.
- **Axios**: HTTP client for API calls.
